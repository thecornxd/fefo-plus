# Сайт с расчётами FEFO+ · для GitHub Pages

Эта папка — готовый сайт. Загружать нужно **её содержимое**, а не саму папку.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | весь сайт одним файлом: 251 КБ, шрифт встроен, интернет не нужен |
| `files/FEFO_plus_model.xlsx` | Excel-модель, 10 листов (включая «9. Риски») |
| `files/FEFO_plus_slides.pptx` | презентация, 15 листов |
| `files/fefo_sim.csv` | выгрузка симуляции 90 дней |
| `.nojekyll` | говорит GitHub: «не обрабатывай файлы через Jekyll» |

## Как выложить — коротко

1. GitHub → **New repository** → имя `fefo-plus` → **Public** → Create
2. **Add file** → **Upload files** → перетащить `index.html`, папку `files`, `.nojekyll`
3. **Commit changes**
4. **Settings** → **Pages** → Source: `Deploy from a branch` → `main` / `/ (root)` → **Save**
5. Через 1–2 минуты сайт на `https://ваш-логин.github.io/fefo-plus/`

Подробно, с разбором ошибок — в файле `ГИТХАБ_PAGES.md` в корне проекта.

## Важно

- Репозиторий должен быть **публичным** (на бесплатном плане Pages работает только так)
- `index.html` обязан лежать **в корне** репозитория, иначе откроется список файлов
- Ссылки внутри сайта относительные — сайт одинаково работает и на своём домене,
  и в подпапке `/fefo-plus/`. Ничего править не нужно

## После публикации

Не забудьте перегенерировать QR на слайде:

```bash
python3 src/make_qr.py https://ваш-логин.github.io/fefo-plus/ --rebuild
```

Сейчас в QR стоит заглушка `https://fefo-plus.example/` — она ведёт в никуда.
